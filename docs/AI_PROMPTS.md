## 0. 文件命名与目录约定

**所有资源最终落到 `Assets/Art/` 下，按类目分子目录**：


**命名规则**：
- 全部小写、下划线分隔
- 角色：`hero_<A|B|C>_<用途>.<扩展名>`
- 其他：`<类型前缀>_<语义名>.<扩展名>`（`bg_` 背景 / `fg_` 前景 / `btn_` 按钮 / `panel_` 面板 / `tag_` 角标 / `banner_` 横幅 / `vfx_` 特效）
- 后续如有补图，按相同规则即可（如 `btn_talk_hover.png`）。

## 1. 全局风格基准（每张图都要带）

> 所有图都必须叠加这段"风格锚"，保证 21+ 张图视觉一致。中文+英文双标，提高跨工具兼容性。

### 1.1 通用风格关键词（Style Anchor）

```
风格：日系二次元半写实插画 (anime semi-realistic illustration),
赛璐璐上色 (cel shading), 精致细节 (highly detailed),
电影感光影 (cinematic lighting), 鲜艳饱和色彩 (vibrant colors),
商业级游戏原画品质 (gacha game CG quality, masterpiece),
插画师风格参考：日系手游立绘
```

### 1.2 通用负面词（Negative Prompt）

```
低质量 (low quality), 模糊 (blurry), 畸形 (deformed),
多余手指 / 多余肢体 (extra fingers, extra limbs),
错误解剖 (bad anatomy), 文字 (text), 水印 (watermark),
多人物 (multiple characters), 杂乱背景 (cluttered background),
不一致光照 (inconsistent lighting), 写实人脸 (photorealistic face),
3D 渲染 (3D render), 未成年 (minor, child)
```

### 1.3 三个角色之间的"一致性"约束

每生成下一个英雄时，prompt 末尾追加：

```
画风、笔触、上色方式、光照角度、镜头距离均与前述其他英雄保持完全一致；
区别仅在于角色本身（发型 / 发色 / 肤色 / 体型 / 服装 / 配饰）。
```

### 2.4 hero_A_recruit.mp4 — 霜刃 · 招募视频

**用途**：阶段四 VideoPlayer 播放  
**输入**：hero_A_pose_bg.png  
**工具建议**：可灵 / 即梦 / Runway Gen-3 / Sora（image-to-video）  
**输出规格**：1080×1920，3.5 秒，24~30 fps，H.264/MP4

```
基于上传的参考图（hero_A_pose_bg.png），生成 3.5 秒招募成功演出视频。

镜头：固定机位，无推拉无移动。

运动设计（按时间轴）：
- 0~1.0s：角色缓慢抬头与镜头对视，发丝在风中轻微飘动，刀刃冰晶粒子稳定飘散
- 1.0~2.5s：右手轻轻转动刀身半圈，冰晶粒子从刀刃迸散到空中
- 2.5~3.5s：嘴角微扬呈克制微笑，眨眼一次，背景冷雾轻微涌动

风格：与参考图完全保持一致，冷色调，电影感光影。

约束：
- 角色五官、发型、服装、配饰**严格不变**
- 不增加新元素（除冰晶粒子和发丝运动外）
- 不改变镜头距离与构图
- 动作幅度小，整体优雅克制（避免动漫夸张动作）
- 循环友好（最后一帧接近第一帧）
```

## 8. 生成顺序建议

按以下顺序生成，便于风格锚定与视频依赖：

1. **先生成霜刃 hero_A_idle.png**作为整体风格基准 → 验收通过后再继续
2. 生成霜刃其他三张 (`hero_A_pose.png` / `hero_A_pose_bg.png` / `hero_A_talk.png`)
3. 生成霜刃视频 `hero_A_recruit.mp4`（输入 pose_bg）
4. 蔷薇全套（idle → pose → pose_bg → talk → mp4），每张都参照霜刃 idle 做风格锁定
5. 朝曦全套
6. 场景：`bg_recruitment.png` → `fg_hands.png`
7. UI 按钮 4 张（同一批次保证风格一致）
8. 属性面板 / SSR+ / ELITE 横幅
9. 引导手指
10. 特效贴图 5 张

**验收要点**：
- 三个英雄并排放在一起，画风、笔触、镜头距离、光照角度必须一致
- 所有 UI 按钮的圆角弧度、描边宽度、高光位置应一致
- 特效贴图边缘必须完全透明（非黑色）
